### 💾 ABOUT THE PROJECT

PIXEL TRACKER is a simple daily task tracker with a colorful retro pixel design.

Create tasks, complete daily goals, earn XP and track your progress!

### 🕹️ FEATURES

- Create and delete tasks
- Mark tasks as completed
- Earn XP for every completed task
- Track daily progress
- Automatically save your tasks

### ⚙️ BUILT WITH

- HTML
- CSS
- JavaScript
- Local Storage
